This project is a containerized microservices digital banking platform using Java 21, Spring Boot, Angular, PostgreSQL, Keycloak, RabbitMQ and WebSocket, with API Gateway routing, JWT authentication, asynchronous event-driven notifications and GitHub Actions CI.
